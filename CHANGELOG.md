# CHANGELOG

This file lists all the updates made to our **Schedify – Task Organizer for Students** project.

## Version v1.3.0 – February 15, 2026

### Added
- Input validation to prevent crashes caused by invalid numeric inputs
- Task Summary feature displaying:
  - Total number of tasks
  - Number of pending tasks
  - Number of completed tasks
  - Completion percentage
   
### Documentation Updates
- Improved README formatting
- Expanded Methodology section
- Added Development Note

### Improved
- System stability and user interaction handling
- Clearer error messages for invalid selections

---

## Version v1.2.1 – February 15, 2026

### Updated
- Project documentation aligned with simplified feature set

### Removed
- Deadline countdown displaying remaining days before due dates
- Automatic task sorting based on earliest deadline
- Motivational message shown upon task completion
- Autosave functionality that stored tasks automatically during execution

---

## Version v1.2.0 – December 5, 2025

### Simplified
- Removed advanced automation features to focus on core task management

### Retained Features
- Task creation with description, deadline, and category
- Viewing tasks in the order they were added
- Task status management (Done/Pending)
- Task update and delete functionality

- Automatic task sorting based on earliest deadline
